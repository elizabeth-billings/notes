# help
```bash
$ git help <command>
```

How to navigate:
- **q** quit manual
- **j** one line down
- **k** one line up
- **d** half page down
- **u** half page up
- **/<term>** search
- **n** next search term
- **N** previous search term

# Config

## Set
```bash
$ git config set --global user.name "<username>" 
$ git config set --global user.email "<email>" 
```

## View 
```bash
$ cat ~/.gitconfig
```

# init 
Create a new git repo 
```bash
$ git init
```
